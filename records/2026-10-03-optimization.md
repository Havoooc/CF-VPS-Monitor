# 2026-10-03 审查问题优化与发布

对应审查：`2026-10-03-code-audit.md`。用户授权执行全部优化，包括同步 GitHub 和 Cloudflare。

## 已实现

1. 普通 JWT 鉴权只接受 `sub=admin` 且没有 WS 用途声明的管理员凭证；WS 票据不能作为 REST Bearer/Cookie。一次性消费登记不可用时拒绝票据。
2. Worker 覆盖客户端传入的内部管理员标记。DO 连接保存已验证权限与公开节点范围，建立连接、重新订阅和广播都检查访问范围；管理员修改可见性时等待权限刷新，私有化站点会关闭公共连接。旧版休眠连接通过重新连接获取权限。
3. `/themes/luminaplus/assets/*` 增加一年 immutable 缓存；哈希文件更新自动产生新 URL。HTML 和版本文件没有采用这种长期缓存。
4. uPlot 随 Instance 详情页加载；调整 React/Query 分包，首页不再预加载图表包。相同 gzip 计算方式下，首屏 HTML 列出的 JS 从 207459 字节降为 183128 字节，减少 24331 字节，约 11.7%。这是构建资源体积对比，不是国内网络端到端测速。
5. 服务器列表/详情支持 `include_replay=0`，跳过未使用的 DO 实时重放请求；LuminaPlus 主动使用该参数，旧客户端默认行为保持兼容。独立路线读取并行执行。
6. 路线缓存按 DB 绑定隔离，合并并发冷读取；写入时使缓存失效，旧的在途读取不能覆盖新缓存。
7. 正式 Shell 和 Go 探针读取固定的三个路线文件；每分钟缓存一次、每文件 64 KiB 上限，坏文件或缺失文件不覆盖已有卡片路线。每日扫描任务安装器与探针代码解耦，不再通过文本补丁增加上报字段。
8. 从现有服务器差异中保留并纳入正式实现：阿里云 NAT 公网 IPv4 覆盖支持；Shell 网络后台进程关闭继承的标准流，动态配置重启移到主循环，避免在配置处理中等待后台进程，同时让新探测目标生效。
